## 3. 缺陷与修复

### 缺陷#1 [P1] 纯下行 TCP 会话被空闲超时误杀 → 已修复（74a2f85）
- 现象：idle=60s 下全速下载会话恰在 60004/60000ms 被切；默认 900s 时即任何 >15 分钟持续下载被静默切断
- 根因：空闲超时是**方向级**——纯下载会话的上行方向无数据，其 Read deadline 60s 到期即断整连接
- 修复：空闲判定改**连接级**（session.lastActive 任一方向有数据即刷新；Read deadline 按 min(连接级截止, 1s 轮询)装填，到期复查 lastActive 被延长则续等）
- 回归：单测（对向活跃期不切+停止后按 idle 超时）+ 161 实测 idle=60 下 150s 纯下载完整传输 rc=0

### 缺陷#2 [P2] install.sh 无参重跑静默改写 data_dir → 已修复
- 现象：非默认 --data-dir 安装后，不带参数重跑 → data_dir 被改回默认 → 服务切空库，管理页规则"全部消失"且无警告
- 修复：已有配置时未显式传参则沿用现有 listen/data_dir（打印沿用提示）；显式传参且不同才变更（附大字警告"原数据不迁移"）
- 回归（170）：显式恢复 /data → 无参重跑打印「沿用已有数据目录 /data」、config 不变、规则 3 条无损

### 修复过程附加教训（如实记录）
- P2 修复首次未生效：python 补丁目标串不匹配被静默跳过（误判成功）；实际部署后 sed 表达式结尾 `|` 在编辑时丢失导致脚本中途退出。两处均已修正并全链路复验——远端脚本类修复必须以「实际执行输出」为验收，不以「本地语法检查」为验收。
