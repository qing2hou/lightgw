SNAT 边界语义（带宽包页验证，2026-10-22 验收）：
- 双客户端并发拥塞：各拿**每源保底**（162 得 2.5M/152 得 1.2M，互不侵占）
- 单客户端独享：借用至**包总额**（3.6M/4M）
- 保底自定义：包编辑设置（0=默认 1M，不得超总额，400 校验）

## 4. 本轮测试发现并修复的缺陷（测试价值所在）

| 缺陷 | 现象 | 根因 | 修复 | 验证 |
| --- | --- | --- | --- | --- |
| **监听地址切换 bind 冲突** | `*:port → IP:port` 修改保存 500，规则陷入不一致态 | applyTCP 先 net.Listen 新地址再关旧——wildcard 与指定 IP 共享内核端口槽位，必现 `address already in use` | **先关旧监听再听新**（失败时尽力恢复旧地址） | `*:11025→40.10:11025→*:11025` 双向 200 + listener 即时迁移 ✅（版本 4ec1035） |
| **SNAT 上传限速从未生效** | 上传 76MB/s 漏网（包额度 4M） | 限速结构挂在入口网卡、按 daddr 匹配——只能命中下载回程；上传经出口网卡发出从不经过 | 拆双向：入口 htb 限下载（daddr=源）+ **出口网卡 htb 限上传（saddr=SNAT 后源）** | ICMP 洪泛 100% 命中出口 class ✅（本轮 A4 复验 1179KB 通过） |

此前轮次已修复并保持回归的缺陷（背景）：多规则 DROP 链序互杀、策略路由 pref 盲删互杀、per-规则统计错归属、带宽包成员表单丢失等 10 余项，详见各 git log。
